企业方案

把团队的开发环境，放到海外的机房里

硬件、机位、电力、网络、系统环境、CI 配置、日常运维 —— 我们交付一整套， 交给团队就能直接开工。

你可能正卡在这几件事上

如果下面任意两条成立，这套方案大概率对你有用。

  • 团队里多人要用海外 AI 开发工具，但每个人的网络环境各不相同，时好时坏
  • iOS / macOS 构建没有合适机器，用 GitHub Actions 的 macOS runner 成本高，自建又没地方放
  • 机器放在办公室，停电、断网、搬工位、员工误操作都会中断任务
  • 没有专人管 IT，环境配置、系统更新、故障处理都压在某个工程师身上
  • 需要发票、合同、对公付款，但市面上的方案多是个人转账，财务过不了
  • 资产归属要求自购设备，但公司没有机房，也没有跨境运维能力

如果你的需求只是「一个人偶尔用一下」，这套方案太重了。 个人场景看常规套餐更合适。

运维与响应

我们做什么

  • 机器在线状态监控，异常时主动排查
  • 现场处置：断电重启、检查指示灯、重新插拔网线或电源
  • 确认硬件故障后按约定流程换机
  • 机房侧问题（电力、网络、门禁）的处理

我们不做什么

  • 不承诺分钟级响应，也不提供 7×24 值班
  • 不负责你系统内部的配置、脚本、CI 逻辑
  • 不登录你的系统修改配置（除非你明确授权某次操作）
  • 不做数据备份 —— 备份是客户的责任，请自行配置 Git 远端或对象存储
  • 不承担因第三方服务不可用导致的业务中断

具体响应时间、故障定义、换机流程写进合同。 没有合同的口头承诺没有意义，我们不在这一页给模糊的 SLA 数字。

一句话概括：我们承诺基础设施层的稳定 —— 机器在线、网络可用、环境交付到位。 上层应用与服务由客户自行负责，这一层我们不做承诺，也不承担相应责任。 具体条款以合同与服务条款为准。

什么情况下这套方案不适合你

  • 只有一两个人用——常规套餐更划算，不用走企业流程
  • 需要 7×24 分钟级响应与正式 SLA 赔付——我们做不到，别签
  • 需要 Windows 或 Linux 环境——我们只有 macOS
  • 需要 GPU 训练算力——Mac mini 不是算力卡，方向不对
  • 构建量很小——按分钟计费的托管 CI 更省，没必要换
  • 要求资产必须自购且不接受托管——这种情况技术上能做，但需要你自行承担跨境寄送与清关

常见问题

最少几台起？

一台起，但批量价从三台开始谈。不过我们建议先租一台验证工作流，确认环境能跑通、依赖能装、构建能过，再扩大台数。一次性上很多台，如果基础流程有问题，返工成本会很高。

多台采购有折扣吗？

有，按台数与周期单独报价。三台以上有多台方案，可以叠加季付九折、半年八点五折、年付八折的周期折扣。台数、周期、线路类型、付款方式都会影响最终单价，需要具体信息才能给出准确数字。加微信或 Telegram 说明台数即可。

可以签合同和开票吗？

都可以。可以按团队需求签服务合同，明确交付内容、可用性口径、故障响应方式与责任边界。发票为国内开具，按正常对公流程走；如需要增值税专用发票，下单时告知即可。

数据安全怎么保证？

机器整机独享，不与其他客户共用，数据存放在你自己的机器上。除你授权的运维操作外，我们不登录你的系统、不查看你的文件。需要物理接触的操作（重启、插拔）会在操作前告知。如果你的数据极度敏感，建议自行开启 FileVault 全盘加密。

同时坏了几台怎么办？

基础现场处置（重启、检查、重新插拔）包含在服务费里。确认是硬件故障的，我们会通知你并按约定流程换机。换机涉及数据迁移和环境重建，这部分时间需要在交付前约定清楚。我们不承诺分钟级响应，具体响应口径写在合同里。

能不能我们自己买机器，放你们机房？

可以，这是机房托管服务，三百元每月每台。机器所有权归你，我们提供机位、电力、网络与基础值守。适合已经有设备、或者出于资产归属要求必须自购的团队。跨境寄送的运费与清关由客户承担。

机器在马来西亚，对国内团队有影响吗？

对 CI 构建没有影响，因为构建在远端跑，只有拉代码和传产物走网络。对交互式操作有影响：SSH 命令行基本无感，图形界面有明显延迟。团队以命令行为主的话，马来西亚位置不是问题。
