这个计算器怎么算的

把逻辑写出来，你可以自己核。

第一步：定档位

按每天实际使用时长判断。Claude Code 的消耗是突发型——一个重构任务可能在 20 分钟内烧掉大量额度，然后你去看结果。所以时长阈值比「月总量」更能反映真实体验：

每天时长建议原因
不到 1 小时Pro（$20）偶尔问问题、写点小脚本，Pro 就够
1–3 小时Max 5x（$100）日常写代码，5x 一般撑得住
3 小时以上Max 20x（$200）长任务多，5x 容易在下午撞限额

额度按滚动 5 小时窗口计算，不是按天或按月。所以「上午用超了下午还能用」是正常的，但连续高强度使用会持续撞限额。

第二步：算成本

四种获取方式的月成本：

  • 官方订阅——只有订阅费，前提是你自己有 Mac、并且网络环境合规
  • 只租 Mac——¥699 首月 / ¥799 续租，账号你自己已经有
  • 租 Mac + 代开账号——机器、线路、账号开通一起，¥1,599 起
  • 自购 Mac + 机房托管 + 自己订阅——机器折旧 ¥125 + 托管 ¥300 + 订阅费

第四种按月成本通常最低，但要一次性投 ¥4,500 买机器，而且网络线路和账号订阅都得自己解决。 这个计算器不会替你隐藏这部分。

第三步：API 按量计费怎么比

不用 token 数反推，直接看盈亏平衡点更准：

  • 你每月 API 账单 低于 $100 → 用 API 更省
  • 账单超过 $100 → Max 5x 开始划算
  • 账单超过 $200 且 20x 仍不够 → 那才是真的重度

参考单价（2026 年 10 月）：Sonnet 5.5 输入 $2 / 输出 $10 每百万 token；Opus 5.5 输入 $4 / 输出 $20。 Claude Code 长任务消耗大，多数重度使用者订阅比 API 更可预测。

常见问题

5x 和 20x 除了价格还有什么区别？

只有用量。两档的模型、功能、优先访问、Claude Code 支持完全一样。20x 比 5x 多付的钱全部用在更高的用量配额上。额度按滚动 5 小时窗口计算。

API 和订阅哪个划算？

看月消耗。Max 5x 每月 100 美元，Max 20x 每月 200 美元。每月 API 账单低于 100 美元用 API 更省；超过 100 美元考虑 Max 5x；长期超过 200 美元且仍不够用才需要 20x。Claude Code 长任务消耗大，重度使用者通常订阅更划算且可预测。

自己买 Mac 加托管，比租便宜吗？

按月成本算通常便宜：Mac mini 按 3 年折旧约 125 元每月，加机房托管 300 元每月，合计约 425 元，比租 Mac 的 699 到 799 元低。但要一次性投入约 4500 元买机器，而且网络、账号、环境都要自己解决。计划用满一年以上、并且有能力自己搞定这些的人，自购更划算。
