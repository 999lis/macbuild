账号只给你自己用，我们只协助开通，不转售、不与他人共用、不走逆向，也不是二手号。

Claude Code 是装好的吗？

是。交付时 Claude 桌面端和 Claude Code 都已经装好，Xcode、Fastlane、Homebrew 等开发工具也一并预装。你拿到连接信息后连上就能用，不需要自己折腾环境。

账号会被封吗？

IP 层面是干净的。设备走马来西亚本地线路，不是机房 IP、不是机场节点、也不是共享代理池。

但我们不保证任何账号不被封。账号状态取决于 Anthropic 的判定与你自己的使用行为（如共享、转售、反代、批量抓取等）。请遵守 Anthropic 的使用政策。因违规使用导致的停用不在我们的责任范围内。

设备是物理机还是虚拟机？

是实体 Mac mini，整机独享。不是虚拟机，也不是分时共享的远程桌面。你拥有完整的硬件资源和管理员权限。

包含 Apple 开发者账号吗？

不包含。本服务只提供 Mac 构建环境。Apple 开发者账号（年费约 $99）需你自行注册，签名证书也请自行配置。我们不接触你的开发者账号。

设备会与他人共享吗？

不会。租期内整台 Mac 只供你一人使用，我们不会在同一台设备上安排其他用户，也不会以虚拟机方式切分。

用你们的机器，账号会被封吗？

IP 层面是合规的。设备使用马来西亚本地线路，马来西亚在 Anthropic、OpenAI 等主流 AI 服务的支持地区列表内，不是机场节点，也不是共享代理池。

但我们不保证任何账号不被封。账号状态取决于各服务商的判定与你的具体使用行为（如是否共享、是否违规自动化）。我们只提供机器，不代持账号，也不干预封禁结果。请遵守各服务的条款。

怎么连接到这台 Mac？

交付时会提供连接地址、端口与账号。推荐使用 Tailscale 组网后 SSH 直连；需要图形界面可用 VNC（macOS 自带屏幕共享即可）。详细步骤见交付时附带的《客户接入指引》。

延迟和速度怎么样？

设备部署在马来西亚吉隆坡机房，从中国大陆访问的往返延迟通常在 180–220ms。这个延迟对 SSH 命令行操作、构建、CI/CD 完全够用；如果你需要重度图形界面操作（如视频剪辑），体感会有延迟。实际表现取决于你本地的网络线路，我们不承诺特定数值。

可以装自己需要的软件吗？

可以。你有管理员权限，可以自行安装任何开发工具。但禁止安装代理、VPN、中转软件、挖矿程序或对外提供网络服务的程序，违规将终止服务。

我的数据安全吗？退租后怎么处理？

整机独享，不与他人共用硬件。我们不会查看你的文件内容与对话记录，但会监控资源占用、网络连接与进程列表以保障服务与合规。退租后抹掉全部数据并重装系统。重要数据请自行备份。

故障了怎么办？

P0 故障（完全无法连接）4 小时内响应，24 小时内修复或换机；一般故障 48 小时内修复。超过 48 小时未解决，可申请按天退款。我们不承诺 100% 在线。

可以中途退租吗？

可以。季付/半年付/年付按已用月数扣除后退还剩余金额（扣 10% 手续费，赠送月份作废）；月付中途退租不退当月。详见服务条款。
